# سجل الملاعب

تطبيق ويب عربي لتسجيل مباريات كرة القدم بين الأصدقاء ومتابعة الترتيب والمواجهات المباشرة. يعمل كتطبيق PWA على الهاتف، ويحفظ البيانات محليًا أولاً في `localStorage`، مع مزامنة سحابية اختيارية عبر Supabase.

## المزايا

- إضافة اللاعبين مع تاريخ الانضمام.
- تسجيل نتيجة كل مباراة وتاريخها وملاحظة اختيارية.
- ترتيب حسب الفوز، الأهداف، النقاط، أو نسبة الفوز.
- تقرير المواجهات المباشرة وإجمالي النتائج وسجل المباريات.
- أرقام الموسم ومشاركة التقارير كصورة، ومنها واتساب.
- نسخ احتياطي واستعادة بصيغة JSON.
- تثبيت على الهاتف والعمل دون إنترنت.
- حساب خاص لكل مستخدم ومزامنة تلقائية بين الأجهزة.
- البحث عن نتائج المستخدمين الآخرين وفتحها للعرض فقط دون دعوة.
- دعوات خاصة بصلاحية **مشاهدة فقط** أو **مشاهدة وتعديل**.
- تغيير صلاحية أي مستخدم مدعو أو إلغاء وصوله في أي وقت.
- حساب مسؤول عام يستطيع تعديل جميع النتائج وإدارة الدعوات: `ayman1793@gmail.com`.

## النشر على GitHub Pages

انشر محتويات هذا المجلد من الفرع الرئيسي عبر **Settings → Pages**. يجب فتح التطبيق عبر HTTPS لتفعيل التثبيت وميزات PWA.

للتجربة محليًا:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## تفعيل قاعدة البيانات المجانية

1. أنشئ مشروعًا مجانيًا في [Supabase](https://supabase.com/).
2. افتح **SQL Editor** وشغّل محتوى [`supabase/schema.sql`](supabase/schema.sql) مرة واحدة.
3. من إعدادات المشروع انسخ **Project URL** و **Publishable key** (أو مفتاح `anon` القديم).
4. افتح التطبيق ثم **الإعدادات → الحفظ السحابي → إعداد الاتصال**، وأدخل القيمتين.
5. أنشئ حسابًا بالبريد أو سجّل الدخول. إذا كان تأكيد البريد مفعّلًا، افتح رسالة التأكيد ثم سجّل الدخول.
6. في **Authentication → URL Configuration** داخل Supabase، اجعل **Site URL** رابط GitHub Pages الخاص بالتطبيق، مثل:

   `https://aymanamin.github.io/Football_Score/`

يمكن وضع القيم العامة في `cloud-config.js` قبل النشر، كي لا يضطر كل جهاز لإدخالها. لا تضع مطلقًا مفتاح `secret` أو `service_role` في ملفات GitHub أو داخل المتصفح.

### ترقية قاعدة موجودة

إذا سبق تشغيل إصدار SQL القديم، شغّل الملف التالي من Supabase SQL Editor:

[`supabase/upgrade-public-results-admin.sql`](supabase/upgrade-public-results-admin.sql)

أو شغّل `supabase/schema.sql` كاملًا مرة أخرى. الترقية تضيف بريد المالك إلى بياناته، وتفعّل البحث العام للقراءة، وتحمي التعديل بسياسات RLS، وتمنح حساب المسؤول المحدد صلاحياته.

## البحث عن نتائج الآخرين

1. يجب أن يكون المستخدم مسجل الدخول.
2. يفتح **الإعدادات → الحفظ السحابي → البحث عن نتائج الآخرين**.
3. يبحث باستخدام البريد الإلكتروني الكامل أو جزء منه.
4. يستطيع فتح النتائج والتقارير، لكن جميع أدوات الإضافة والحذف والتعديل تكون معطلة.
5. لا تتحول صلاحية البحث العام إلى تعديل إلا إذا أضافه المالك بدعوة **مشاهدة وتعديل**.

النتائج العامة متاحة للقراءة فقط لجميع الحسابات المسجلة، وليست متاحة للمستخدم المجهول غير المسجل.

## الدعوات والصلاحيات

1. سجّل الدخول بحساب مالك النتائج، ثم افتح **الإعدادات → الحفظ السحابي**.
2. في قسم **المستخدمون المشاركون** اكتب بريد المستخدم.
3. اختر **مشاهدة فقط** أو **مشاهدة وتعديل** ثم أضفه.
4. أرسل له رابط GitHub Pages؛ عليه إنشاء حساب أو تسجيل الدخول بنفس البريد المضاف.
5. يستطيع المستخدم اختيار النتائج المشتركة من قائمة **مساحة النتائج**.
6. يستطيع المالك تغيير الصلاحية أو إلغاء الوصول في أي وقت.

صلاحية المشاهدة تمنع التعديل في الواجهة وفي قاعدة البيانات. وصلاحية التعديل تسمح بإضافة اللاعبين والمباريات وتعديلها. يظل بإمكان المستخدم رؤية نسخة سبق تخزينها على جهازه دون إنترنت، لكن جلب النسخة السحابية وتحديثها يخضع للصلاحيات الحالية.

## طريقة المزامنة

- يبقى التطبيق صالحًا للعمل محليًا دون حساب أو إنترنت.
- بعد تسجيل الدخول، تُزامن أي إضافة أو تعديل تلقائيًا.
- عند فتح التطبيق على جهاز آخر بالحساب نفسه، تُستعاد أحدث نسخة.
- عند تعارض نسختين، تعتمد المزامنة النسخة الأحدث حسب وقت آخر تعديل.
- عند وجود أكثر من محرر، يعتمد آخر تعديل تمت مزامنته؛ يفضّل إجراء مزامنة قبل بدء تعديل كبير.
- سياسات Row Level Security تسمح بالقراءة العامة للحسابات المسجلة، بينما تحصر التعديل في المالك أو المحرر المدعو أو المسؤول العام.

## الملفات المهمة

- `index.html` واجهة التطبيق.
- `app.js` منطق اللاعبين والمباريات والتقارير.
- `cloud-sync.js` التسجيل والمزامنة مع Supabase.
- `cloud-config.js` إعداد الاتصال وإضافة البحث العام وصلاحية المسؤول.
- `supabase/schema.sql` إنشاء الجداول والسياسات الكاملة.
- `supabase/upgrade-public-results-admin.sql` ترقية قواعد البيانات الموجودة.
- `service-worker.js` التثبيت والعمل دون إنترنت وتحديث ذاكرة التطبيق.
