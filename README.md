# سجل الملاعب

تطبيق ويب عربي خفيف لتسجيل مباريات كرة القدم بين الأصدقاء ومتابعة الترتيب والمواجهات المباشرة. يعمل بالكامل داخل المتصفح، ويحفظ البيانات في `localStorage` دون خادم أو قاعدة بيانات.

## التشغيل

يمكن فتح `index.html` مباشرة للاستخدام الأساسي. لتفعيل التثبيت والعمل دون إنترنت، شغّل الملفات من خادم HTTPS أو خادم محلي، مثلاً:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## المزايا

- إضافة اللاعبين وتسجيل تاريخ انضمام كل لاعب.
- تسجيل مباراة بين لاعبين مع النتيجة والتاريخ وملاحظة اختيارية.
- ترتيب حسب الفوز، الأهداف، النقاط، أو نسبة الفوز.
- تقرير المواجهات المباشرة وإجمالي النتائج وسجل كل مباراة.
- أرقام الموسم: الهداف، الأكثر فوزًا، أكبر نتيجة، وأكثر مواجهة تكرارًا.
- مشاركة أي تقرير كصورة عبر قائمة المشاركة في الهاتف، ومنها واتساب.
- نسخ احتياطي واستعادة بصيغة JSON.
- تطبيق PWA قابل للتثبيت ويعمل دون إنترنت.

## الخصوصية

البيانات محفوظة محليًا على الجهاز فقط. حذف بيانات المتصفح قد يحذف السجل، لذلك يُنصح بتنزيل نسخة احتياطية دوريًا.
